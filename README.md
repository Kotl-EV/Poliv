# Полив

Отдельный веб-сервис для проекта автополива. Это не яйцо Jarus и не копия чужого каталога оборудования.

Редактор идёт по шагам: подложка, зоны, вода, спецификация. Чертёж (JPEG, PNG или PDF) только подложка: зоны с картинки не читаются. Пользователь обводит газоны, клумбы и дорожки, ставит точку ввода воды и нажимает «Рассчитать схему» — тогда появляются дождеватели, капля, трубы и клапаны. Диаметр берётся из выбранного ряда ПЭ (SDR 9, 11, 13,6, 17 или 17,6) так, чтобы скорость воды была не выше 1,5 м/с. Внутренние диаметры заданы таблицей. Расход по трубе суммируется от потребителей к источнику. Потери напора считаются по Дарси–Вейсбаху: шероховатость 0,005 мм, вода 15 °C. У источника задаются давление и лимит расхода. Осадки зоны — расход дождевателей и капли внутри неё, делённый на площадь. Норма зоны (газон 6 мм, клумба 8 мм, дорожка 0) делится на эти осадки и даёт минуты полива. Микроклимат умножает норму: тень 0,7, открытый участок 1, ветер 1,3. Почва и уклон задают впитывание: если осадки выше, тот же объём делится на циклы с паузой. Клапан делит сеть на станции: они поливаются по очереди, каждая работает по своей самой долгой зоне, а магистраль считается по самой большой. Капельная трубка задаётся шагом и расходом капельницы. Траншея считается по длине напорных труб: по умолчанию 0,3 м шириной и 0,4 м глубиной. Фитинги — тройники, углы, крестовины, переходы и заглушки — получаются из узлов сети.

## Запуск

Нужен Node.js 24 или новее.

```bash
npm install
npm test
npm run dev
```

Сайт открывается на http://127.0.0.1:5173 . Данные лежат в `data/poliv.db`, подложки — в `data/backgrounds`.

Прод (один процесс, сайт + API):

```bash
npm run build
npm start
```

## Pterodactyl

Как Jarus: импортируешь яйцо, сервер слушает основной порт панели.

1. Админка → Nests → Import Egg → `egg-poliv.json`
2. Create Server, образ **Node.js 24**, один порт
3. `GIT_REPO` — `https://github.com/Kotl-EV/Poliv` (или свой). Пусто — залей файлы через SFTP
4. Start. В консоли будет `Poliv is listening`
5. Сайт: `http://IP:PORT`

База и подложки в `data/` при переустановке не затираются. `AUTO_UPDATE=1` заново ставит npm-пакеты при старте.

Кнопка «Пример» ставит участок 13,2 × 8,8 м на ряде ПЭ SDR 11: четыре веера по 360 л/ч, начало магистрали ПЭ 25 (3,2 м) и остальные трубы ПЭ 20 (22 м). Давление источника 3 бар.
